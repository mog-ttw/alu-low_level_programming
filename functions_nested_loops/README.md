# C - Functions, nested loops

This project contains C programs that demonstrate functions, nested loops, character handling, arithmetic operations, and number formatting.

## Tasks

- 0. `_putchar` — prints `_putchar`.
- 1. `print_alphabet` — prints the lowercase alphabet.
- 2. `print_alphabet_x10` — prints the lowercase alphabet ten times.
- 3. `_islower` — checks whether a character is lowercase.
- 4. `_isalpha` — checks whether a character is alphabetic.
- 5. `print_sign` — prints the sign of an integer.
- 6. `_abs` — calculates the absolute value of an integer.
- 7. `print_last_digit` — prints and returns the last digit.
- 8. `jack_bauer` — prints every minute of a day.
- 9. `times_table` — prints the 9 times table.
- 10. `add` — adds two integers.
- 11. `print_to_98` — prints integers from a given number to 98.

## Compilation

The programs are compiled using GCC with the following flags:

`-Wall -Werror -Wextra -pedantic -std=gnu89`

## Requirements

- Ubuntu 20.04 or a compatible C development environment.
- GCC compiler.
- The provided `_putchar` function for tasks that require character output.
