# C - Variables, if, else, while

This project contains C programs that demonstrate variables, conditional statements, loops, and character output.

## Requirements

- Ubuntu or a compatible Unix-like environment
- GCC compiler
- Compilation with `-Wall -Werror -Wextra -pedantic -std=gnu89`

## Tasks

| File | Description |
|---|---|
| `0-positive_or_negative.c` | Determines whether a randomly generated number is positive, negative, or zero. |
| `1-last_digit.c` | Prints the last digit of a number and describes its value. |
| `2-print_alphabet.c` | Prints the lowercase alphabet. |
| `3-print_alphabets.c` | Prints lowercase and uppercase alphabets. |
| `4-print_alphabt.c` | Prints lowercase letters except `e` and `q`. |
| `5-print_numbers.c` | Prints single-digit numbers using `printf`. |
| `6-print_numberz.c` | Prints single-digit numbers using `putchar`. |
| `7-print_tebahpla.c` | Prints the lowercase alphabet in reverse. |
| `8-print_base16.c` | Prints hexadecimal digits in lowercase. |
| `9-print_comb.c` | Prints single-digit numbers separated by commas and spaces. |

## Compilation

Compile an individual source file using:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 FILE.c -o program
```
